lumentoSTORE

The archive on your NAS. It takes in photos and videos from lumento LOAD on your iPhone and from camera cards read on your computer. It checks every file byte for byte, names it by when it was taken, and files it in ordinary month folders, in a place you choose.

FreeAsustor · x86-64 and ARMOne package, no dependenciesPairs on your local network
Setup

Four steps.
No console.

STORE is a single package from App Central. It doesn't need Docker, a database server or any other package. It creates and manages its own TLS certificate.

  1. Install lumento STORE from App Central.
  2. Claim it. Open its admin page and set a password. The first password set in the five minutes after a fresh install owns it. If you miss that window, restart the app from App Central to open a new one.
  3. Pick a folder. Choose where your archive should live. STORE never assumes a default and never needs a share with a special name. It creates a single _lumento folder inside the one you pick and leaves everything else there alone.
  4. Pair a device. Start pairing on the NAS, and your iPhone finds STORE on the local network. Enter the six-digit code and you're done.
What it does

Accept it, check it, file it.
Then leave it alone.

Checked before it's accepted

STORE computes its own SHA-256 fingerprint from the bytes that actually arrived. A file whose fingerprint doesn't match is never stored.

Camera-card import, built in

Open STORE's admin page and read a camera card straight into your archive from your browser. The browser fingerprints every file before sending it, so STORE checks each one against a fingerprint it didn't make. RAW+JPEG pairs stay together, and a card you've already imported isn't copied twice. In our test, a 10 GB card went from a MacBook's card reader to the NAS in 3 minutes over Wi-Fi 6. Your speed depends on your card reader, your network and your NAS.

Named by when it was taken

Each file is renamed by the moment it was taken, like 2026.09.14 18.03.52.120.HEIC, and filed in _lumento/2026.09/ and so on. A video is dated from its own bytes: an iPhone video by its own clock and time zone, a camcorder clip by the camera's own clock. When STORE can't read a date, the name says it's an estimate. The original name stays in the import report. You choose the date style in STORE's settings. They're ordinary files in ordinary folders, so any other app can read them.

Nothing stored twice

A file the archive already holds is recognised by its exact fingerprint, whichever paired device sends it, and isn't written again. For your phone, that check happens before any bytes are sent.

Written safely to disk

A file only counts as archived once it's been written all the way to disk and moved into its final place in one step, and its folder entry is on disk too. After a power cut you get either the whole file or no file.

Destinations

Set up named destinations, such as a folder for each child, and choose one on the phone before a Load. The phone remembers your last choice.

Never moves or deletes

Once STORE has archived a file, it never moves or deletes it. You can reorganise the archive however you like.

Remembers for the phone

The NAS keeps a record of what it's received and checks new files against the archive by fingerprint. Reinstall LOAD, or bring a new iPhone, and photos already in the archive aren't sent again.

Import receipts

Each session ends with a report from the NAS itself, built from its own records, not just the phone's account of what happened. It lists each file's new name beside the old one.

Pull the card, carry on

If the card comes out mid-import, STORE waits 18 minutes for it. Put it back and the import carries on. If you don't, the run ends and says plainly that it's partial.

A full disk loses nothing

If the NAS fills up, STORE keeps every file it has, tells the phone to wait, and carries on once there's room again.

Pairing that can't be guessed

Pairing starts on the NAS and works only on your local network. The six-digit code never crosses the network, and each code works for one try. The phone fixes the NAS's certificate as part of the exchange. Repeated failures lock that address out, and a NAS-wide limit stops attempts from many addresses at once. Unpair a device on the NAS, or forget the NAS on the phone, and it stops at once.

One archive, two ways in

Phone and camera card, same rules.

lumento LOAD on your iPhone and the camera-card import in your browser both send files to STORE. The import page is part of STORE, and lumento ONE shows it to your household too. Both use the same protocol, so files from both are named, filed, checked and de-duplicated the same way.

STORE doesn't need lumento ONE: import a card from STORE's own admin page. ONE doesn't need STORE to show your photos, but its card import is STORE's page. Together, a card fresh from the camera ends up in the same archive as your phone's photos, and when the run is done the screen tells you whether everything on the card is on the NAS.
