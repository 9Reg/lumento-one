lumentoSTORE

The archive on your NAS. It receives files from lumento LOAD on your iPhone and from lumento ONE's camera-card import. It checks every file byte for byte, then files it in ordinary folders that you own.

Asustor · x86-64 and ARMOne package, no dependenciesLocal network only
Setup

Four steps.
No console.

STORE is a single package from App Central. It doesn't need Docker, a database server or any other package. It creates and manages its own TLS certificate.

  1. Install lumento STORE from App Central.
  2. Claim it. Open its admin page and set a password. The first password set on a fresh install owns it. If you miss that window, restart the app from App Central to open a new one.
  3. Pick a folder. Choose where your archive should live. STORE never assumes a default and never needs a share with a special name. It creates a single _lumento folder inside the one you pick and leaves everything else there alone.
  4. Pair a device. Start pairing on the NAS, and your iPhone finds STORE on the local network. Enter the four-digit code and you're done.
What it does

Accept it, check it, file it.
Never lose it.

Checked before it's accepted

STORE computes its own SHA-256 fingerprint from the bytes that actually arrived. A file whose fingerprint doesn't match is never stored.

Written safely to disk

A file only counts as archived once it has been written all the way to disk and moved into its final place in one step. After a power cut you get either the whole file or no file.

No duplicates, ever

Duplicates are recognised by exact fingerprint, across every session and every paired device. For your phone, that check happens before any bytes are sent.

Plain month folders

New files go into _lumento/2026.09/ and so on, by the date the photo was taken. They're ordinary files in ordinary folders, so any other app can read them.

Destinations

Set up named destinations, such as a folder for each child, and choose one on the phone before a Load. The phone remembers your last choice.

Never moves or deletes

Once STORE has archived a file, it never moves or deletes it. You can reorganise the archive however you like.

Remembers for the phone

The NAS keeps a record of everything it has received. If you wipe or reinstall your iPhone, LOAD still knows what's already safe.

Import receipts

Each session ends with a report from the NAS itself, not just the phone's own account of what happened.

Pairing that can't be guessed

Pairing starts on the NAS, works only on your local network, and fixes the NAS's certificate on the phone. Repeated wrong codes lock that address out, and a NAS-wide limit stops attempts from many addresses at once.

One archive, two ways in

Phone and camera card, same rules.

lumento LOAD on your iPhone and lumento ONE's camera-card import in your browser both connect to STORE as paired devices. They use the same protocol, so files from both are named, filed, checked and de-duplicated the same way.

STORE doesn't need lumento ONE, and ONE doesn't need STORE. Each one works on its own. Together, a card fresh from the camera ends up in the same archive as your phone's photos, and the screen tells you when the card is safe to format.
